# Test react project

This project is written by somebody _very_ inexperienced. So please fix bugs and improve it!

## Installation and running

Once you have the repository cloned, you can simply run it with these commands:

```bash
npm install -g pnpm # skip if you already have pnppm installed locally
pnpm install
pnpm dev
```

## Unit testing

To run unit tests, run
```bash
pnpm test
```

## Technologies used

To keep it simple, only very basic technologies are being used here:
* Typescript – for type checking
* React – for rendering the UI
* Vite – for the basic project structure
* Vitest + React testing library – for unit tests (Vite is an alternative to Jest and has an almost identical usage)
